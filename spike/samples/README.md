# Spike sample corpus

| Files | Origin | License |
|---|---|---|
| `et_*` | Test images from the Image::ExifTool 13.55 distribution (`t/images/`), © Phil Harvey. Real camera metadata (MakerNotes, RAW containers); image data is mostly stripped, so these files are tiny. | Same terms as Perl itself (Artistic License or GPL). Used only as test data. |
| `synth*` | Generated by `../tools/gen_corpus.py` (Pillow 12.3, pillow-heif 1.8, pidng) and tagged with exiftool 13.59. | Created for this project. |

Notes on individual files:

* `et_Panasonic.rw2` has its raw data removed: `RawDataOffset` points 22 bytes before end of file and the strip runs
  past EOF. exiftool therefore hashes "to end of file", so *any* append changes its `ImageDataHash`. Real RW2 decoders
  can make the same assumption, which is one reason RAW formats are written via sidecar.
* `et_QuickTime.heic` has no Exif item, `et_PNG.png` stores text/EXIF chunks after IDAT, `synth.dng` has a duplicated
  `DNGBackwardVersion` tag (pidng quirk). These are kept deliberately as awkward inputs.
