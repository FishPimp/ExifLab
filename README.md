# ExifLab

Android app (in development) for viewing and losslessly editing photo metadata: EXIF, XMP, IPTC, MakerNotes and ICC.
It handles JPEG, HEIC/HEIF, PNG, WebP, DNG and common camera RAW formats. It is offline-first: image data never
leaves the device.
